Plate IV · the reason it cannot disagree with itself

It is a theorem,
not a machine.

State is a last-writer-wins map ordered by a hybrid logical clock and actor id. Merge is the least upper bound of two replicas. Shapiro, Preguiça, Baquero, Zawirski — 2011. We run the algebra in your browser every load. If it fails, the page will say so.

A ⊔ B = B ⊔ A   (commutative)
(A ⊔ B) ⊔ C = A ⊔ (B ⊔ C)   (associative)
A ⊔ A = A   (idempotent)
∴ (S, ⊔) is a join-semilattice, and Ω is unique.

Your replica identity is —. Every mutation is ECDSA P-256 signed. Forged events are dropped. Presence is a TTL on #p/{actor}.

Plate V · hitch any website — exact steps

One script.
Any origin.

This is the whole vendor relationship. There is no dashboard. Do these steps on a shop, a game, a blog — they become one backend if they open the same name.

  1. Put aether.js on the site Copy the file next to your HTML, or hotlink the URL below. CORS is already *. It is a static file, not an API.
  2. Invent a secret namespace Long, random, unpublished. The string is the database URL, the API key, and the lock. Optional: add passphrase so even swarm lurkers see only AES-GCM ciphertext.
  3. Open it instead of Firebase const db = await Aether.open('your-secret'). That is initializeApp + getFirestore + auth, in one call.
  4. Read and write Collections db.col('users').doc(id).set(data), live queries .where().on(), counters, files, rules, capsules. Full map is in README.md.
  5. Hitch the next website Different origin, same aether.js, same namespace string. WebRTC does not care what domain you are on. Proof: elsewhere.
  6. Check the network tab Static files, torrent trackers, MQTT, STUN. No fetch to a vendor of yours. If that list is all you see, you did it.

Plate VII · colophon

      
Nothing to shut down.

      

        

          You cannot DDoS an address that is not an address. You cannot subpoena
          a company that is a file. You cannot migrate off a vendor, because the
          vendor is a 20-byte hash. The cost is zero because nobody is selling
          you cycles. The failure mode is honest: if the mesh dies, the last
          browser still holds the lattice, and the theorem still holds.
